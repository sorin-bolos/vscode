Component Structure

The ChatWidget component includes:

  • Header - Displays title and clear button
  • Messages Area - Scrollable chat history with user and assistant messages
  • Input Area - Text input with send button, supports Enter to send
  • Loading State - Animated typing indicator
  • Events - Emits events for message sending, receiving, and chat clearing

Features

  • ✅ Responsive design that matches VS Code's styling
  • ✅ Message history with timestamps
  • ✅ Auto-scrolling to latest messages
  • ✅ Loading states with typing indicators
  • ✅ Keyboard shortcuts (Enter to send, Shift+Enter for new line)
  • ✅ Event-driven architecture for easy integration
  • ✅ Programmatic message adding via ref methods
  • ✅ Clear chat functionality
  • ✅ Customizable props (title, placeholder, disabled state)

Usage Example

To use this component in a Vue.js project:

<template>
  <div class="app">
    <ChatWidget
      title="AI Assistant"
      placeholder="Ask me anything..."
      @message-sent="handleMessageSent"
      @message-received="handleMessageReceived"
      @chat-cleared="handleChatCleared"
    />
  </div>
</template>

<script>
import { ChatWidget } from '@vscode/chat-widget'

export default {
  components: { ChatWidget },
  methods: {
    handleMessageSent(event) {
      // Handle the sent message
      console.log('Message sent:', event.message);
    }
  }
}
</script>
